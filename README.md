# Beeza

Beeza is a lightweight fintech website with an interactive spending-app prototype. It helps users explore daily spending, budgets, savings, and expense entry.

## Run locally

Open `index.html` in a browser. No installation or build step is required.

## Prototype notes

- Uses sample data stored in the browser; changes reset when the page reloads.
- Does not connect to a bank or upload receipt images.
- Voice entry depends on browser support; manual entry is also available.

## Files

- `index.html` — website and prototype structure
- `styles.css` — layout and styling
- `app.js` — interactive behavior
